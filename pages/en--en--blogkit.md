    <div class="bk-feature"><span class="bk-feature-icon">01 / ✍</span><h3>Write in Markdown</h3><p>Articles are Markdown files. Set only the metadata you need—such as title, publication date, and URL—in JSON. HTML article bodies are supported too.</p></div>
    <div class="bk-feature"><span class="bk-feature-icon">02 / ⚡</span><h3>Generate everything needed to publish</h3><p>Article listings, search, RSS, sitemap, and Open Graph images. One build creates the static files ready for publishing.</p></div>
    <div class="bk-feature"><span class="bk-feature-icon">03 / ◈</span><h3>Comfortable reading experience</h3><p>Syntax highlighting, code copying, and links to related articles. Designed to read well on desktop and mobile.</p></div>
    <div class="bk-feature"><span class="bk-feature-icon">04 / ▤</span><h3>Manage ordinary files</h3><p>Articles in Markdown, settings in JSON. No database or proprietary dashboard holding your content hostage.</p></div>
    <div class="bk-feature"><span class="bk-feature-icon">05 / ↗</span><h3>Automate publishing with GitHub</h3><p>Combine GitHub Actions or Cloudflare Pages to automate publishing when you update your content.</p></div>
    <div class="bk-feature"><span class="bk-feature-icon">06 / ✦</span><h3>Works well with AI</h3><p>Markdown and JSON make it easy to work with AI on drafts and metadata. You can write without AI, too.</p></div>
