# Markdownから、自分のブログを公開する

OJapp Blog Kitは、Markdownで書いた記事を自分のドメインで公開するための小さなブログエンジンです。

## 記事を書く

記事本文は `content/` にMarkdownファイルとして保存します。メタ情報は必要なものだけ `articles.json` に書きます。タイトルは本文の最初の見出しから自動で取得できます。

```js
// 記事を追加したらビルド
npm run build
```

## 自分の場所に積み上げる

GitHubへPushするとCloudflare Pagesが静的HTMLを配信します。記事の元データは普通のMarkdownとJSONなので、サイトの表示方法や公開先を変えても持ち運べます。

| 元データ | 生成されるもの |
| --- | --- |
| Markdown | 記事ページと一覧 |
| JSON | 検索データ、RSS、サイトマップ |

まずは書くことに集中できる状態を作る。それがこのキットの出発点です。
